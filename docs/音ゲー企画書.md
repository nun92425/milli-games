# 音ゲー企画書（Milli Pulse）

## 1. 現状の実装状況

- 形式: 4レーン縦落下型（D/F/J/K + タッチ入力）
- ノーツ: tap / hold
- 難易度: EASY / NORMAL / HARD（`note.lvl` 0/1/2 で振り分け、HARDは準備中の表示あり）
- 収録曲:
  - Princess Viral / 音ノ乃のの（BPM 134）
  - ルミナス / 音ノ瀬らこ（BPM 170）
  - おきらくスーパースター / 小廻こま（BPM 178）
- 全曲 1番サビまでで終了（実際の楽曲には 2番・ラスサビまで存在する）
- 対応済み機能: ベストスコア / リトライ / フェードアウト / オフセット調整

---

## 2. 将来案①: LONG（フル）バージョン

- 概要: 現状1番サビで終わるが、楽曲フル（2番・ラスサビまで）の譜面を追加する案
- 方針: 曲リストに「◯◯（FULL）」として別カードで追加（推奨方式A）
  - `SONGS` に別id（例: `okiraku_superstar_full`）を追加
  - チャートJS に `CHARTS.◯◯_full` を追加（videoIdは既存動画のまま、`duration`延長 + ノーツ追加）
  - ベストスコア・リトライ・難易度UIは songId 単位で自動分離される
- 対象曲・難易度: 全曲/全レベルにするか、一部のみかは作成者の気力次第
- 状態: 未着手（着手時期未定）

## 3. 将来案②: Orbital（オービタル）モード

円形音ゲー。※元企画書に図版あり・このメモでは未収録

### 3-1. コンセプト・概要

画面中央の判定エリアを中心に、ノーツが円の周りから回転しながら流れてくる！
従来のレーン型とは異なる、新しいプレイ体験を提供する「円形音ゲー」モード。
プレイヤーの視線を中央に集め、直感的かつダイナミックなリズムアクションを実現する。

### 3-2. ノーツの種類

| ノーツの種類 | アクション・仕様 |
|---|---|
| タップ | タイミングに合わせて単押しタップ！ |
| ホールド | 長押しで継続してポイントを獲得！ |
| スライド | 判定の円周に沿って指をスライド！ |
| フリック | 指定された矢印の方向にフリック！ |
| スペシャル | 特定の条件で出現！高スコア獲得のチャンス！ |

### 3-3. モードの特徴（アピールポイント）

- **360度からのアプローチ**: 360度どこからでもノーツが飛んでくるため、プレイヤーに新しい緊張感を提供
- **楽曲との完全シンクロ**: 曲のテンポや展開に合わせて、回転速度やエフェクトが変化
- **ダイナミックなUI変化**: サビの盛り上がりに合わせて、円（判定ライン）自体が拡大・縮小する視覚ギミックを搭載
- **世界観との融合**: 「Milli+Pulse（ミリプロ）」の世界観に合わせた専用演出で、楽曲をさらに深く楽しめる

### 3-4. プレイ中のフロー（演出の段階変化）

楽曲の進行に合わせて演出が3段階で変化し、没入感を高める。

1. **通常パート**: ノーツが一定の速度で回転してくる基本のフェーズ
2. **サビパート（演出強化）**: 円が拡大し、回転が加速！エフェクトも一気に華やかになり楽曲の盛り上がりを演出
3. **フィーバー／クライマックス**: 背景やノーツのデザインが激変！視覚的な派手さが加わり、プレイの爽快感はMAX

### 3-5. 基本システム・UI

- 画面表示: 中央にキャラクター/ジャケットを配置。上部に「COMBO」「SCORE」「クリアランク（C〜SS）」、左下に「LIFE」ゲージを配置
- 機能: ポーズ機能、および「AUTO」機能の切り替えボタンを搭載

### 3-6. 技術メモ（実装時の参考）

- ノーツ形式 `{ t, l, type, d, lvl }` はそのまま流用可能。`l`（0-3）を角度（上/右/下/左 = 0°/90°/180°/270°）に割り当て
- 描画: 判定線を「中心のリング」に変更、ノーツは円周から中心へ放射状に移動
- 入力: タッチ位置の角度からレーン判定へ変更（`getLaneFromX` → `getLaneFromAngle`）
- エンジン改造が大きいため、単独フェーズでの実装を推奨
- 状態: 未着手（着手時期未定）
